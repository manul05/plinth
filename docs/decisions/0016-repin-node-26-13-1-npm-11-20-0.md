# ADR-0016: Re-pin Node.js to 26.13.1 and npm to 11.20.0

- **Status:** Accepted
- **Date:** 2026-11-25
- **Decided by:** Owner
- **Owner approval:** Owner, 2026-11-25: "Node/npm decision - re-pin Plinth to 26.13.1 / 11.20.0"

## Context
Stage 3 pinned Node.js `24.16.0` and npm `11.13.0` (ADR-0003, ADR-0004, `docs/04-architecture.md` §2). Before starting T-M0-02 on the owner's Windows PC, the installed toolchain was checked: `node -v` is `v26.13.1` and `npm.cmd -v` is `11.20.0`, with no Node version manager (`nvm`, `fnm`, `volta`) installed.

## Options
1. **Install Node 24.16.0 locally** and keep the Stage 3 pin.
2. **Re-pin Plinth to Node 26.13.1 and npm 11.20.0**, amending the toolchain versions in ADR-0003 and ADR-0004 while keeping npm workspaces and runtime-neutral library rules unchanged.

## Decision
Option 2. Re-pin Plinth's runtime/tool/CI Node.js version to `26.13.1` and npm to `11.20.0`, so local development and CI match the installed environment.

## Consequences
`.nvmrc` is `26.13.1`, root `package.json` uses `"engines": { "node": ">=26.13.1 <27" }`, `packages/ts/package.json` uses `"engines": { "node": ">=26.13.1" }`, and CI (`actions/setup-node` reading `.nvmrc`) installs Node `26.13.1`. `@types/node` (`24.19.2`) remains unchanged until T-M0-02/CI verifies typechecking on Node 26. `AGENTS.md` is owner-managed and left unchanged for the owner to update if desired.
