# ADR-0001: Adopt the portfolio repo conventions v1

- **Status:** Accepted
- **Date:** 2026-10-31
- **Decided by:** Owner (programme rule)
- **Owner approval:** Programme rule: ADR-0001 in every repo is "Adopt the portfolio repo conventions v1"

## Context
Every portfolio repo starts from the same skeleton so agents behave the same everywhere.

## Options
1. **Conventions v1** (skeleton, Rule 0, hooks, size caps, branch model): no design work; agents already know it.
2. **Own conventions**: no benefit for a kit.

## Decision
Adopt conventions v1 as copied from the portfolio template on 2026-10-31 (`<!-- template: repo-conventions v1 (2026-10-28) -->`).

## Consequences
Hooks, deny rules, main-alarm, `docs/status/` handoff apply. The merge phrase is `now it is time to merge plinth to main`.
